# Minesweeper Online!

## This repository is a version of the game minesweeper with some added functionality.

Here is the link to the game online: https://lupovita.github.io/proj-mine-sweeper/

## Featured Buttons By Functionality:
- Smiley Button:
    Image of a smiley. When clicked, the game will reset.

- Difficulty levels:
    Buttons with the difficulties : 'Begginer, Medium, Expert' written on them. When clicked, the game will reset and
    the board will change its size and mines amount according to the chosen difficulty.
    * Begginer - Size: 4x4, Mines: 2.
    * Medium - Size: 8x8, Mines: 14.
    * Expert - Size: 12x12, Mines 32.

- Hint Button:
    Image of a lightbulb. Can be used only while the game is running. When clicked, the lightbulb lightens up. If a cell
    is clicked while the lightbulb is on, it will be revealed for 1.5s. To cancel the effect, click on the bulb again.

- Safe Click:
    Image of a magnifying glass. Can be used only when the game is running. When clicked, a random cell with no mine in
    it will be revealed for 1.5s.

- Undo:
    Can be used only when the game is running. When clicked, the game will go one step backwards.

- Light Or Dark Mode:
    Images of a moon and a sun. toggles between lightmode and darkmode.

- Manual Mode:
    Image of building tools. Can be used only before starting the game. When clicked, all the cells are revealed and you
    can place mines on the board as you please. When finished setting the board, click again on the button and
    start the game by clicking one of the cells.

- Mega Hint:
    Image the writing 'MEGA'. Can be used only when the game is running. When clicked, you can click on 2 different
    cells to define an area that will be revealed for 2s, can be used only once. To cancel the effect, click on the
    button again.

- Exterminate Mines:
    Image of a mine. Can be used only when the game is running. When clicked, 3 random mines will be exterminated from
    the board.
